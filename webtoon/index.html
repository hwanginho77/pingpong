1웹툰 사이트에서 자동 스크롤

네이버·카카오 등 브라우저로 보는 웹툰 페이지에 자동 스크롤 버튼을 띄워 줍니다 (북마클릿).

⏬ 툰스크롤

PC: 노란 버튼을 북마크바로 끌어다 놓기 · 휴대폰: 코드 복사 후 아래 방법대로 북마크 만들기

휴대폰(안드로이드 크롬)에서 설치하기
  1. 위의 북마클릿 코드 복사를 누릅니다.
  2. 크롬에서 아무 페이지나 북마크(☆)로 저장한 뒤, 북마크 수정을 엽니다.
  3. 이름을 툰스크롤로, URL 칸은 지우고 복사한 코드를 붙여 넣어 저장합니다.
  4. 웹툰 회차를 연 상태에서 주소창에 툰스크롤을 입력하고, 아래에 뜨는 ☆ 북마크를 누르면 실행돼요.
아이폰(사파리)에서 설치하기
  1. 위의 북마클릿 코드 복사를 누릅니다.
  2. 아무 페이지에서 공유 버튼 → 북마크 추가로 저장합니다.
  3. 북마크 목록 → 편집 → 방금 만든 북마크를 눌러 이름은 툰스크롤, 주소는 복사한 코드로 바꿉니다.
  4. 웹툰 회차 페이지에서 북마크 목록을 열고 툰스크롤을 누르면 실행돼요.
사용법
  1. 실행하면 화면 아래에 조작 바가 나타나고 바로 스크롤이 시작돼요.
  2. ▶/⏸ 재생·정지, − / + 로 속도 조절. 화면을 손가락으로 누르고 있으면 잠깐 멈춰요.
  3. 다시 북마클릿을 누르거나 ✕ 를 누르면 꺼져요.

웹툰 앱(네이버 웹툰 앱 등) 안에서는 동작하지 않고, 브라우저로 연 웹툰 페이지에서 동작해요.

2내 기기의 웹툰 이미지 보기

저장해 둔 웹툰 이미지(또는 폴더)를 열어 이어 붙여 자동 스크롤로 봅니다. 파일은 기기 밖으로 나가지 않아요.

또는 이미지 파일을 여기에 끌어다 놓기

파일 이름 순서(1, 2, … 10)대로 정렬해서 보여 줘요.
